Logo

A j made from one pen stroke

The mark is a lowercase j drawn in a single line, with the dot as a highlighter hit. It stays readable at favicon size. In the wordmark, "jot" sits on a highlighter swipe and "ern" stays plain, so the name reads as jot + intern.

App icon, ink

Default. Use on light grounds and as the app icon.

App icon, highlighter

For dark grounds and slide covers.

Mark only

No tile. Ink j on a highlighter ground.

jotern

Horizontal lockup

Mark left, wordmark right, set in Bricolage Grotesque ExtraBold with tight tracking. Never change the highlight to another color.

Clear space

Keep a margin of x around the mark, where x is the width of the dot.

Small sizes

Favicon at 16 px, browser tab at 32, desktop shortcut at 64 and up.

Color

Ink, paper and a highlighter

Dark blue ink on cool paper, with one highlighter yellow for whatever the intern should notice. Margin red marks the notebook edge and offline state, never a call to action.

Typography

Friendly headlines, plain body, mono for exports

Bricolage Grotesque gives the name its slightly bent, handwritten feel. Public Sans keeps long entries easy to read. JetBrains Mono is for dates, durations and Markdown, so the app looks like the files it produces.

Voice

Short, direct, written for someone tired at 5 pm

An intern fills this in at the end of a work day. Every string should take less time to read than to ignore.

Ready for the Angular styles
